## 🚀 Featured projects

### [Street Show 2026](https://github.com/rymarczyk-tomasz/StreetMeetingProject) · [streetshow.pl](https://www.streetshow.pl/)

Official website of Street Show 2026 by Street Meeting Poland, a car event at Polsat Plus Arena in Gdańsk. Multi-page site with gallery, FAQ, ticket links and registration forms. I took care of SEO (sitemap, canonical URLs, meta tags), performance (Lighthouse), PWA manifest and automated deployment with GitHub Actions.

`HTML` `CSS` `JavaScript` `GitHub Actions`

### [Sheet Burning Calculator](https://github.com/rymarczyk-tomasz/SheetBurningCalculator)

A work-time standard calculator for a manufacturing company. It estimates processing time for thermal cutting, sawing and waterjet cutting based on part geometry (shape, dimensions, thickness, holes), and also works as a quick reference for other processes like heat treatment, welding or beveling. Keyboard-friendly, built to be used every day.

`React` `JavaScript` `Vite` `ESLint` `Prettier`

### [Theodor Buchholz – artist portfolio](https://github.com/rymarczyk-tomasz/Project-Crouzen) · [live demo](https://rymarczyk-tomasz.github.io/Project-Crouzen/)

Portfolio website for a painter. Content is stored in JSON and managed through a Sveltia CMS admin panel, so the artist can add and hide artworks without touching code. Hosted on GitHub Pages, no build step.

`HTML` `CSS` `JavaScript` `Sveltia CMS` `GitHub Pages`
